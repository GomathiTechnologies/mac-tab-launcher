Privacy Policy — Mac Tab Launcher

Effective date: November 26, 2026

Overview

Mac Tab Launcher is a Chrome extension designed to provide a visual interface for managing open browser tabs.

Data Access and Usage

The extension accesses the following information solely to provide its core functionality:

  • Open browser tab titles.
  • Open browser tab URLs.
  • Website favicons.
  • Active tab status.
  • Browser tab group names and colors.

This information is processed locally within the user's browser.

Data Storage

Mac Tab Launcher does not maintain a browsing history database or transmit tab information to a developer-operated backend. Local browser storage may be used to retain appearance preferences and recent tab IDs for shortcut functionality. Whiteboard drawings and embedded images are stored locally in the browser.

External Resources

The extension may retrieve website favicon images from external websites to display recognizable website icons. These requests may be subject to the respective websites' privacy policies. Optional Excalidraw features may open external websites or request external resources when used.

Data Sharing

Mac Tab Launcher does not sell user data, use it for advertising, or share it with data brokers.

Analytics and Tracking

The extension does not use analytics, advertising trackers or user profiling.

Permissions

The tabs and tabGroups permissions are used to provide visual tab management, searching, filtering, switching, closing and split-view functionality. The storage permission is used for recent-tab shortcuts.

Changes to This Policy

This privacy policy may be updated to reflect future changes to the extension.
